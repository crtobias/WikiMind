# Web — TurnoYa

> Hub del repo `web/`: Next.js con dos partes, la página pública de reservas (`/r/*`) y el panel del local (`/panel/*`).

- Correr: `npm run dev` (`:3000`). Necesita el Back en `:4000` (`NEXT_PUBLIC_API_URL`).
